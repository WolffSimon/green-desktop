# Green desktop

A from-scratch, browser-based tribute to the 1985 GEM desktop, drawn into a 640 × 200 four-colour screen buffer the way a medium-resolution colour monitor showed it. No emulator, no ROM images: just one self-contained HTML file.

Double-click **Floppy disk A**, then **DEMO.EXE**, to run a 320 × 200 bouncing-ball demo with raster bars, a starfield, a sine scroller and a square-wave chiptune. Press M for music on or off; space, Esc or a click returns to the desktop.

Also in this repo: `playground.html`, three interactive canvas animations (a Perlin-noise flow field, flocking boids and a morphing torus knot).

Both pages are single static files, so they run straight from GitHub Pages or from a local copy opened in a browser.
